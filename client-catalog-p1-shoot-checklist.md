## BATCH CHECKLIST

Film **only P1 rows** below before breaking down a setup; order matches `client-catalog-production-shoot-list.md` batches.

### Batch 1 — Barbell + rack

- **Equipment needed:** Power rack, barbell, plates
- **P1 exercises to film before changing setup:** Snatch-Grip Deadlift; Zercher Squat
- **Setup changes required:** Load bar; swap grip/stance between deadlift, row, Zercher, Bradford, JM as needed.

### Batch 2 — Dumbbell + bench

- **Equipment needed:** Dumbbells, flat/incline bench, floor mats
- **P1 exercises to film before changing setup:** Renegade Row; Alternating Dumbbell Curl; Standing Dumbbell Curl; Incline Front Raise; Incline Lateral Raise; Plate Front Raise
- **Setup changes required:** Adjust bench angle (flat/incline/prone); swap DB weights; floor vs bench positions.

### Batch 3 — Cable station

- **Equipment needed:** Cable tower, attachments (rope, handles, straight bar, ankle strap)
- **P1 exercises to film before changing setup:** Cable Woodchop; Cable Pullover; Cable Shrug; High Cable Row; Single-Arm Cable Row; Cable Shoulder Press; Cable Internal Rotation; Cable Overhead Triceps Extension; Cable Skull Crusher; Rope Overhead Triceps Extension
- **Setup changes required:** Change pulley height and attachment (handle, rope, bar, ankle strap) per exercise.

### Batch 4 — Resistance bands

- **Equipment needed:** Band anchor, loop bands, Spanish squat strap
- **P1 exercises to film before changing setup:** Band Overhead Triceps Extension
- **Setup changes required:** Re-anchor band height; swap band tension; Spanish squat strap setup once.

### Batch 6 — Landmine corner

- **Equipment needed:** Landmine pivot, barbell
- **P1 exercises to film before changing setup:** Landmine Row; Landmine Lunge
- **Setup changes required:** Grip/end position on bar; standing vs lunge stance.

### Batch 7 — Machines

- **Equipment needed:** GHD, reverse hyper, row machines, standing leg curl
- **P1 exercises to film before changing setup:** Glute-Ham Raise; Reverse Hyperextension
- **Setup changes required:** Move between machines; adjust pads and foot plate per device.

### Batch 12 — Plyo / box / steps

- **Equipment needed:** Plyo boxes, stairs edge, platforms
- **P1 exercises to film before changing setup:** Barbell Step-Up; Dumbbell Step-Up
- **Setup changes required:** Box height; add/remove barbell or dumbbells; stairs edge for calf raise.

### Batch 13 — Specialty bars

- **Equipment needed:** Trap bar, safety squat bar (SSB)
- **P1 exercises to film before changing setup:** Trap Bar Shrug; Safety Bar Squat
- **Setup changes required:** Swap trap bar vs SSB on rack; load plates per lift.
